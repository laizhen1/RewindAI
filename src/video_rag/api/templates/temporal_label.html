How to add one question / 怎样添加一道题
  1. Play a short part of the video and write a question and a short answer based on it. / 播放一小段视频，根据内容写一道问题和简短答案。
  2. Seek to where the explanation starts and ends, using the two time buttons below. / 分别跳到讲解开始和结束的位置，点击下方两个时间按钮。
  3. Choose the evidence type and select “Yes” if the video answers the question, then save the local draft. / 选择证据类型；视频能回答时选“可以”，然后保存本地草稿。

You can start with one answerable question. Mark an entire video unanswerable only after checking it for that question. / 先做一道有答案的题即可。只有针对某题检查完整段视频后，才能标记该题无答案。
