Local answer review / 本地回答复核

Watch the original video and verify the reference, generated answer and every claim. A caveat does not erase an unsupported claim. Stop if a reference is wrong; correct the source labels and regenerate the review. Your declaration is not independent verification. / 请回看原视频，核对参考答案、生成回答和每一项陈述。如果参考标签有误，请先修改标签并重新生成复核文件。自行声明不代表独立核验。

How to review each answer / 如何逐题核对
  1. Play the reference timestamp and check that the question and reference answer match the video. If the reference is wrong, correct the source label and regenerate the draft. / 点击参考时间回看视频，先核对问题和参考答案；参考有误时应修正原标注并重新生成草稿。
  2. Choose Correct only when the answer addresses the question and agrees with the video. Choose Incorrect for an error or an unsupported claim, even if the answer also includes a caveat. / 回答切题且与视频一致才选“正确”；有错误或无依据的陈述请选择“错误”，即使回答同时包含免责声明。
  3. Choose Supported only when the displayed model input and video support every substantive claim. A merely related excerpt is not enough. If an answer happens to be correct but is not supported by the model input, select Incorrect or unsupported for this evidence-grounded score. Use Not applicable only for an abstention without unsupported claims. / 模型输入和视频支持回答的每项实质内容才选“有证据”；片段仅仅相关并不足够。回答即使碰巧正确，若模型输入没有支持，请在此证据评分中选择“错误或无证据”。仅在未作答且没有无依据陈述时选择“不适用”。
  4. Save progress if you need a break; save the reviewed copy only after completing every question. / 可以先保存进度；全部题目完成后再保存复核副本。
