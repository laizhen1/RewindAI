# Public English-language sample videos

These short educational videos can be used to try the local workspace without using a restricted course recording. They are not included in the repository, and a successful demo is not an accuracy benchmark.

The file pages identify the videos as [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Review each source page and the license before redistributing or adapting the materials; attribution, license links, change notices and share-alike terms can apply. The RewindAI code license is separate. Check the TimedText page and its history for subtitle authorship and reuse conditions when sharing subtitles.

To try a video, download its original WebM from the Commons file page, then use **Add lecture** in RewindAI. If you supply subtitles, save the timed text as a UTF-8 `.srt` file rather than saving the surrounding HTML page. Alternatively, leave subtitles empty and use the locally cached Whisper model for transcription. In both cases, verify wording and timestamps against the video.

The application copies the selected video to local storage; neither these sample files nor your private lectures are included in the repository. See the [React setup and privacy guide](REACT_WORKSPACE.md) for setup and cleanup details. For the earlier local smoke-test record, see the [Chinese sample notes](PUBLIC_SAMPLE_ZH.md).
